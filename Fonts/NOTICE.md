# Fonts

`Roboto-English.json` and `Roboto-Cyrillic.json` are subsets of Roboto Regular, stored as Type Foundry documents.

- English keeps U+0020 through U+007E.
- Cyrillic keeps U+0400 through U+04FF. The source file has no U+0487.

The outlines were read from the typeface JSON at `fonts/cyrillic/roboto/Roboto_Regular.json` in https://github.com/7dir/json-fonts (MIT, copyright 2017 Mike). The font data is Roboto, copyright Google, licensed under the Apache License 2.0. A copy of that license is `LICENSE-APACHE.txt`.

These two files are the sample faces. Opening another typeface JSON or a web font does not add it to this folder.
